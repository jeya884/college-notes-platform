🚀 Quick Start (5 Minutes)

Step 1: Create Supabase Account

Go to supabase.com and sign up for FREE

Step 2: Add Supabase Keys

1. Copy your Project URL and Anon Key from Supabase Dashboard

2. Edit js/config.js and replace:

const SUPABASE_URL = 'YOUR_PROJECT_URL'; const SUPABASE_ANON_KEY = 'YOUR_ANON_KEY';

Step 3: Setup Database

1. Go to Supabase → SQL Editor → New Query

2. Copy all content from docs/DATABASE_SCHEMA.sql

3. Paste & Click Run

Step 4: Run Locally

Option A: Use VS Code Live Server

  • Install "Live Server" extension
  • Right-click index.html
  • Click "Open with Live Server"

Option B: Use Python

python -m http.server 8000

Then open: http://localhost:8000

Step 5: Test Features

  • ✅ Sign up with test email
  • ✅ Browse notes
  • ✅ Try downloading
  • ✅ Test admin panel (use @admin email)
